# WorkBuddy Skills 与连接器使用规范

- 优先使用 WorkBuddy 中已经安装并连接的 Skills 和连接器。
- 使用某个 Skill 前，先核实其准确名称、当前可用状态和能力范围。
- TAPD 是正式需求、缺陷、任务和迭代状态的事实来源。
- 在连接器已授权且可用时，可从企业微信收集反馈或发送研发通知。
- 只有工具返回成功结果后，才能报告对应操作成功。
- 如果 Skill 或连接器不可用，应说明限制，并生成可供人工处理的材料。
- 不得编造 Skill、连接器、接口或自动化能力。
- 本目录只规定何时、为何使用 Skill，不复制 Skill 的实现内容。
