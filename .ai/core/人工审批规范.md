# 人工审批规范

AI 可以分析、整理和提出建议，但以下操作必须获得用户明确批准后才能执行：

- 创建或修改正式 TAPD 需求、缺陷和任务。
- 确认产品需求、业务规则和验收标准。
- 定稿技术设计和任务拆解。
- 修改项目源代码（除非用户已经明确授权当前任务的代码修改范围）。
- 修改数据库结构或执行数据库迁移。
- 修改认证、授权、权限、加密或敏感数据处理逻辑。
- 新增依赖、外部服务或基础设施。
- Git commit、push、merge、发布、部署或生产环境操作。

审批只对明确描述的范围有效。如果实施范围发生实质变化，必须重新请求审批。

不得将 AI 自己生成的方案视为已经获得用户批准。
