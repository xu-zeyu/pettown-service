## 结构化自审

本项无独立审查人，逐文件结构化自审结果：

- `UserAuthServiceImpl` 和 `LoginFailureGuard`：只对已注册用户的错误密码计数，验证码失败不计入；锁定在验证码校验后返回，避免匿名探测账号存在；注册并发去重保留。
- `RedisLoginFailureGuard`：单个 Redis 脚本原子增加失败数，并在第 5 次重置 15 分钟到期；Redis 缺失时拒绝已注册用户登录。
- `AuthController`、`ErrorCodeEnum`、`GlobalExceptionHandler`：参数、验证码、密码与锁定使用不同业务码，锁定 HTTP 423；成功响应结构不变，错误不输出凭证。
- 小程序配置及 `.env.example`：新签发 token 默认 604800 秒；管理端配置未变。
- 测试：覆盖错密锁定、锁定期间正确凭据、错误分类、不重复注册、令牌时长及 Redis 缺失。

## 残余风险

- 已签发令牌仍可能按原到期时间有效；本项把新签发小程序令牌设为 7 天，不执行全量会话撤销。
- 部署环境的 `PETTOWN_TOKEN_TIMEOUT` 或配置中心若覆盖为其他值，会覆盖默认 7 天；发布前需核对最终配置。
