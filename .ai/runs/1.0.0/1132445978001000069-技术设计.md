## TAPD 验收与仓库现状

TAPD 要求 `GET /api/miniapp/user/me` 登录态返回 id、phone、昵称、头像、注册来源、注册时间；验收为「有效 token 返回完整资料；无 token/过期 token 返回未登录错误码」。

仓库现状：`UserController.me` 已返回 `userId、phone、nickname、avatarUrl`（MINIAPP-V1-04 交付）；`User` 实体已有 `source`（UserSourceEnum）与 `createdAt`，尚未输出到 me 响应。

## 方案

1. `UserInfoResponse` 扩展 `source`、`registeredTime` 两字段：`source` 输出 `UserSourceEnum` 名称（如 `MINI_PROGRAM`），`registeredTime` 输出注册时间（实体 `createdAt`，格式与既有 `createdTime` 字段一致的 ISO 序列化）。不新增接口、不改路由，OpenAPI 操作数保持 15。
2. 鉴权沿用 MiniappUserSessionInterceptor（USER 会话逐请求校验）：无 token、伪造 token、已吊销（登出后）token 均由 `NotLoginException` 统一映射为 401「请先登录」，即满足未登录错误码验收；过期与吊销走同一失效路径，用例以吊销与伪造 token 固化。
