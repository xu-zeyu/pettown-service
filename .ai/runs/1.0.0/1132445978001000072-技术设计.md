# 技术设计：1132445978001000072 — 小程序创建宠物档案

- 项目 ID：`pet-system`
- TAPD：[1132445978001000072](https://www.tapd.cn/32445978/prong/stories/view/1132445978001000072)，P0，状态“规划中”
- 设计状态：用户已批准新增可空字段及编写 SQL，数据库执行由用户后续负责
- 编写日期：2026-11-05

## 一、需求摘要

`POST /api/miniapp/pets` 创建完整宠物档案：名称 1–30 字、物种 `CAT/DOG/OTHER`、品种、性别、生日、体重 0–200 kg、绝育状态、头像。归属 ID 仅取当前登录用户。每个用户至多 20 只宠物。必填缺失不得落库，创建成功返回含 ID 的档案，超上限返回独立业务码。

## 二、现有实现分析

`Pet` 实体及 App 端 `PetServiceImpl` 目前仅有 ID、名称、物种、归属 ID；小程序尚无宠物 Controller。仓库仅有三处测试用 `pet` 建表 SQL，未发现生产 `pet` 基线建表文件或自动迁移框架。Miniapp 启动扫描当前未纳入宠物 Mapper/Service。现有 App 宠物接口要保持兼容。

## 三、建议技术方案

1. 扩展共享 `Pet` 实体，新增可空的 `breed`、`gender`、`birth_date`、`weight_kg`、`sterilized`、`avatar_url` 字段；现有名称与物种列保持不变。建议 MySQL 类型依次为 `VARCHAR(100)`、`VARCHAR(16)`、`DATE`、`DECIMAL(5,2)`、`BOOLEAN`、`VARCHAR(2048)`。旧行保持空值，不回填臆造数据。
2. 小程序新增请求 DTO、响应 VO、Controller 与业务服务；采用现有 Sa-Token 用户命名空间获取 `ownerId`，不接受客户端传入归属 ID。物种接口值使用 `CAT/DOG/OTHER`；性别暂只按可空文本和列长度处理，不臆造枚举；生日按日期类型解析，不新增年龄限制。校验必填、长度与体重范围。
3. 创建事务中锁定对应用户行，再统计该用户宠物数并插入，以防并发越过 20 只；异常时整体回滚。归属校验与已有 App 服务隔离，避免改变 App 创建契约。
4. 编写新库建表 SQL 和已有旧表加列 SQL，并更新小程序、App、业务模块的 H2 测试 schema。**不执行生产数据库迁移**；用户后续根据实际库状态选择并执行脚本，先对照真实运行库 DDL 核对。

## 四、影响模块与文件

- `module-business`：Pet 实体、Mapper/Service，必要的行锁查询及测试。
- `module-miniapp`、`pettown-boot/miniapp`：小程序接口、扫描配置和集成测试。
- `pettown-boot/app`：共享实体扩展后的回归测试 schema。
- `docs/sql`：待批准的增量迁移脚本；不自动执行。

## 五、接口与数据模型变更

新增 `POST /api/miniapp/pets`；不修改 App 现有 `/api/pets` 成功响应。`pet` 新字段均允许空值以兼容旧记录；名称和物种非空校验在服务端执行。

## 六、权限与安全考虑

接口要求小程序用户登录；`ownerId` 完全由登录态派生。响应仅返回本人新建的档案；超额和非法输入不落库。并发上限需以数据库事务验证。

## 七、兼容性与数据迁移

新实体查询旧库前必须完成对应加列迁移，否则可能出现未知列错误。仓库缺少运行库 `pet` 表的权威 DDL，脚本只能按已知测试 schema 起草，执行前必须核实。

## 八、异常处理与可观测性

参数错误与超额使用不同业务码；日志不包含额外用户资料。保留请求追踪 ID 便于定位插入失败。

## 九、测试策略

先写红灯接口测试：无 token、必填缺失、字段边界、创建成功、归属不可伪造、20 只上限和并发创建。实现后运行模块测试、全仓 `./gradlew build` 及迁移脚本对照检查。

## 十、回滚方案

回滚小程序接口及实体读取依赖；已新增的可空列保留，避免破坏已写入的档案数据。生产迁移如需回退另行评审，不自动删列。

## 十一、备选方案

仅在 JSON 扩展字段保存档案可避免加列，但现有表无该列且查询能力弱，不采用。若真实生产表已有这些列，应调整脚本为差异校验而不重复加列。

## 十二、假设与待确认问题

- 当前生产 `pet` 表的实际 DDL 未在仓库发现；用户要求先按仓库已知测试结构编写代码及 SQL，后续自行建表或迁移。
- 物种使用英文 `CAT/DOG/OTHER`；性别可选值与头像 URL 来源未在 TAPD 中细化，本项不加未确认的业务限制。
