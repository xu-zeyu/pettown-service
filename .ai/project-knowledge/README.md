# 项目专属知识

本目录只存放当前项目的业务和技术事实。不同项目必须分别维护，禁止将其他项目的业务资料复制到这里。

建议按需建立以下文件：

- `project-overview.md`：项目定位、用户和范围。
- `modules.md`：功能模块地图及实现状态。
- `architecture.md`：当前架构和数据流。
- `business-rules.md`：已经确认的业务规则。
- `database-schema.md`：核实过的数据库结构说明，不包含敏感数据。
- `known-risks.md`：已确认风险和待解决问题。

不得在本目录保存账号密码、访问令牌、证书私钥、个人敏感信息或生产环境数据。
